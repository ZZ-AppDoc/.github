# Prerequisites

These are communicated by email/Teams post/chat etc given you need this info to get here. But the list that follows is the definitive guide to getting here,
so that's what gets maintained and sent to people.

- Create a GitHub account in the format “zz-fullname” (so I’m zz-gordoncoulter).
- Secure it with 2FA.
- [Download and install GitHub Desktop](https://desktop.github.com/download/)
- [Download and install VS Code](https://code.visualstudio.com/download)
- Create a folder c:\users\{username}\source\zz\AppDoc
- Don your sandals :-)
- Open a command prompt and enter the following (replace the name!):
  - `git config --global user.name "zz-gordoncoulter"`
  - `git config --global user.email "gordon.coulter@zenzero.co.uk"`
  - Then check the settings have taken with: `git config --list`
- Let either Stuart Ferguson or Gordon Coulter know that you're done and they'll add you to the relevant GitHub organisation.

While you're waiting you can [familiarise yourself with Markdown](https://commonmark.org/help/), the "language" we use to write our documents. But don't panic, its not really a language. We write
using the same basic text you get when using Notepad, with some added "decorations" to give us style. It's really very simple and quickly becomes second nature.
