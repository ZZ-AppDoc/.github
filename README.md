# Welcome
Welcome to the **Application Documentation** repo.

When you're writing, please follow the [Microsoft Style Guide](https://learn.microsoft.com/en-us/style-guide/welcome/). 

If you're using AI, please ensure you're only using our Enterprise Copilot option. **We can't have customer proprietory knowledge 
ending up in the world's general AI pool and being used to train it**. That's a non-negotiable, so please don't think you've come up with a special case for using one of the free ones.

If you're using AI to "assist" with your writing, tell it to **write in the style defined in the Microsoft Style Guide**. 

When you're reading documentation here, you should struggle to determine who wrote it because we should all sound the same. If you want to see how that works, 
read any bit of Microsoft documentation. 

# Your committment
There's an onus on everyone creating/editing documentation to ensure it's of a high standard. 

If you read documentation and it's wrong/outdated, **please fix it**. Don't leave it for some other poor soul to go through the same pain you've likely just
had to determine that document didn't help.
