# Configure VS Code

Open VS Code.

## Profiles

Select the menu option: `File -> Preferences -> Profiles`.

Click the down arrow on the `New Profile` button and navigate through `From Template` and select `Doc Writer`

![Adding a new profile](<Using VS Code for Markdown editing and GitHub source control/2025-05-02-09-56-23.png>)

Click the `Create` button.

![Creating a new profile](<Using VS Code for Markdown editing and GitHub source control/2025-05-02-09-44-44.png>)

Click `Trust Publishers & Install`.

![Trust Publishers and Install](<Using VS Code for Markdown editing and GitHub source control/2025-05-02-09-58-15.png>)

Click `Add Folder` and browse to the App Doc folder you created when doing the Prerequisites configuration.

![Adding a folder](<Using VS Code for Markdown editing and GitHub source control/2025-05-02-11-37-22.png>)

Activate the profile by clicking the Tick.

![Activate the profile](<Using VS Code for Markdown editing and GitHub source control/2025-05-02-11-42-57.png>)

You can also switch profiles via the menu `File -> Preferences -> Profiles`

![Activate the profile - via menus](<Using VS Code for Markdown editing and GitHub source control/2025-05-02-11-45-24.png>)
